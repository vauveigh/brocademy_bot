## Критерии завершения MVP

### Минимальный работающий продукт готов, когда:
- ✅ Пользователь может зарегистрироваться и выбрать уровень
- ✅ Пользователь получает 3 задания в день
- ✅ Multiple choice задания проверяются автоматически
- ✅ Open question сохраняются для проверки преподавателем
- ✅ Прогресс сохраняется и отображается
- ✅ Автоматический переход между днями и темами работает
- ✅ Ежедневная автоматическая рассылка работает
- ✅ Веб-интерфейс для проверки ответов работает
- ✅ Базовая документация готова
- ✅ Нет критических багов

### Метрики успеха MVP:
- 10+ пользователей активны ежедневно
- 80%+ заданий выполняются без ошибок
- Время ответа бота < 2 секунд
- Uptime > 95%
- 0 критических багов

## Заметки

### Порядок разработки
1. Начинать с базы данных (Этап 1)
2. Затем интеграция с Notion (Этап 2)
3. Затем базовый бот (Этап 3)
4. Потом логика заданий (Этап 4)
5. Остальное по приоритетам

### Тестирование
- Тестировать каждый этап перед переходом к следующему
- Иметь минимум 1 тестовую тему в Notion на каждом этапе
- Тестировать с реальными пользователями после Этапа 6

### Git workflow
- Создавать feature branch для каждого этапа
- Делать коммиты после каждой завершенной задачи
- Merge в main только после тестирования
- Использовать semantic commit messages
