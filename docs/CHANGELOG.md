- DatabaseManager класс для работы с БД
- 8 индексов для оптимизации запросов

- Валидация данных с проверкой диапазонов значений
- Детальное логирование всех операций с БД

- Автоматическая логика переходов:

- Статистика с разбивкой по типам заданий (grammar, reading, vocabulary, situations, review)

- Тестовый скрипт для проверки открытых вопросов (test_open_answers.py)
- JOIN запросы с таблицей users для получения username и level
- Поддержка пагинации через параметр limit
- Фильтрация ответов по статусу проверки (checked/unchecked/all)

  - **Middleware**:
