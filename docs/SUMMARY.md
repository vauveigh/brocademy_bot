# Сводная документация проекта

## Обзор проекта

**English Learning Telegram Bot** - это бот для ежедневной практики английского языка с системой тематических циклов. Каждый пользователь получает 3 задания в день на протяжении 5 дней для изучения одной темы.

## 🎯 Ключевые концепции

### Тематический цикл

```
1 Тема = 5 дней = 15 заданий

День 1: Grammar (3 задания)      → Грамматические упражнения
День 2: Reading (3 задания)      → Чтение и понимание текста
День 3: Vocabulary (3 задания)   → Словарный запас
День 4: Situations (3 задания)   → Жизненные ситуации
День 5: Review (3 задания)       → Повторение всей темы
```

### Уровни сложности

- **Beginner** (A1) - начальный уровень
- **Elementary** (A2) - элементарный уровень
- **Advanced** (B1-B2) - продвинутый уровень

### Типы заданий

1. **multiple_choice** - выбор из вариантов (inline-кнопки)
   - Автоматическая проверка
   - 70-80% всех заданий
   
2. **open_question** - открытый ответ (текст)
   - Проверка преподавателем
   - 20-30% всех заданий

## 📊 Архитектура данных

### Notion Database (Задания)

```
Хранение: Все задания по всем темам и уровням
Структура: 12 полей + метаданные
Фильтрация: По уровню, теме, дню, номеру задания
Редактирование: Через веб-интерфейс Notion
```

**Основные поля:**
- ID задания (BEG-FAMILY-D1-G1)
- Тема (Family and Friends)
- Порядок темы (1, 2, 3...)
- Уровень (Beginner/Elementary/Advanced)
- День цикла (1-5)
- Номер в дне (1-3)
- Вопрос, варианты, ответ, объяснение
- Медиа (URL + тип)
- Статус (draft/active/archived)

### SQLite Database (Пользователи)

```
Хранение: Профили, прогресс, ответы пользователей
Таблицы: 3 (users, user_progress, user_answers)
Обновление: При каждом действии пользователя
Аналитика: Статистика выполнения заданий
```

**Таблица users:**
- Профиль пользователя
- Текущая позиция (тема, день, задание)
- Дата последней активности

**Таблица user_progress:**
- История всех выполненных заданий
- Правильность ответов
- Статистика для analytics

**Таблица user_answers:**
- Ответы на открытые вопросы
- Очередь для проверки преподавателем
- Статус проверки

## 🔄 Жизненный цикл задания

### 1. Создание в Notion
```
Преподаватель создает задание
↓
Заполняет все поля
↓
Устанавливает Status = "active"
```

### 2. Выдача пользователю
```
Бот получает задание из Notion
↓
Фильтрация: уровень + тема + день + номер
↓
Отправка с inline-кнопками (или текст)
```

### 3. Ответ пользователя
```
Multiple choice → Автопроверка → Объяснение
Open question → Сохранение в БД → Проверка преподавателем
```

### 4. Обновление прогресса
```
Сохранение в user_progress
↓
Обновление позиции (task_in_day++)
↓
Если выполнены 3 задания → переход к следующему дню
↓
Если завершен день 5 → переход к следующей теме
```

## 📈 Прогресс пользователя

### Трекинг позиции

```python
user.theme_order = 1          # Первая тема
user.current_theme = "Family and Friends"
user.current_day = 3          # День 3 (Vocabulary)
user.task_in_day = 2          # Задание 2 из 3
```

### Переход к следующему заданию

```python
# После выполнения задания:
task_in_day += 1

# Если выполнены все 3 задания дня:
if task_in_day > 3:
    current_day += 1
    task_in_day = 1

# Если завершен цикл (5 дней):
if current_day > 5:
    theme_order += 1
    current_day = 1
    task_in_day = 1
    current_theme = [новая тема из Notion]
```

## 🎨 Примеры заданий

### Multiple Choice (Beginner)

```
Вопрос: Choose the correct possessive adjective: 
        "This is ___ brother."

Варианты (inline-кнопки):
[  my  ] [  mine  ]
[  me  ] [   I    ]

Правильный ответ: my

Объяснение: We use "my" before nouns to show possession. 
            "Mine" is used without a noun.
```

### Open Question (Elementary)

```
Вопрос: Describe your typical morning routine in 3-4 sentences.

Тип: Открытый ответ (текстовое поле)

Эталонный ответ (для преподавателя):
"I wake up at 7 am. I have breakfast and take a shower. 
 Then I go to work by bus."

→ Ответ отправляется преподавателю для проверки
```

## 🛠 Технический стек

### Backend
- **Python 3.11+** - основной язык
- **aiogram 3.x** - Telegram Bot Framework
- **notion-client** - работа с Notion API
- **aiosqlite** - асинхронная работа с SQLite
- **APScheduler** - планировщик задач

### Storage
- **Notion** - хранение заданий (NoSQL)
- **SQLite** - хранение пользователей (SQL)

### AI & APIs
- **OpenAI GPT-4** - генерация заданий
- **Telegram Bot API** - взаимодействие с пользователями

### Web Interface
- **Flask** - веб-сервер для преподавателя
- **Jinja2** - шаблоны HTML
